# 📝 作文批改

拍照上传学生作文 → AI 按《中考作文评分标准（60 分）》批改，给出**分数、档次、逐段批注、
修改后全文**，还能继续追问。手机、平板、电脑都能用。

```
┌────────────┐   ┌──────────────┐   ┌────────────────┐
│  拍作文照片  │ → │  AI 识别正文   │ → │  按评分标准打分   │
│ （或传文档） │   │ （错了可改）    │   │  + 逐段批注      │
└────────────┘   └──────────────┘   └────────────────┘
                                          ↓
                                   修改后全文 + 提分建议
                                   ⬇️ 一键下载 TXT 报告
```

## 快速开始

```bash
sh setup.sh
```

就这一句。第一次跑会依次问你：

1. 建虚拟环境、装依赖（**只有 Flask 一个包**，需要联网）
2. **设置一个访问口令**（输两遍）
3. **选端口**（回车 = 8083，选过的会记住）
4. 启动服务，自动打开浏览器

之后再跑还是这句 —— 依赖直接跳过，并且：

- **改口令**：提示「直接回车保持不变」，想换就输入新口令（输两遍）
- **换端口**：提示「端口 [回车 = 上次的]」，输个新数字就换，会记住

⚠️ **没设口令 = 网站整体锁定**：网页会显示「请在终端运行 `sh setup.sh` 设置口令」，
不存在「不设口令谁都能进」的状态。网页里的设置页也只能**改**口令、不能清空。

**对局域网开放：**

```bash
HOST=0.0.0.0 sh setup.sh     # 让局域网里别的设备也能访问（默认只有本机能访问）
PORT=9000 sh setup.sh        # 临时指定端口（优先级高于 setup.sh 里记住的）
```

### 环境要求

- Python **3.8 或更高**
- 能联网（只有第一次装依赖时需要）

Ubuntu / Debian 如果报建虚拟环境失败：

```bash
sudo apt install python3-venv
```

## 配置 AI 接口

跑起来后，进网页 → 右上角 **⚙️ 设置** → 填你的 AI 接口。

支持任何 **OpenAI 兼容**的接口，页面里有三个现成预设：

| 服务商 | 接口地址 | 模型 |
|---|---|---|
| 小米 MiMo | `https://api.xiaomimimo.com/v1` | `mimo-v2.6-flash` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-flash` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 自己填 |

选一个预设 → 填上你的 **API Key** → 保存。也可以存**多套配置**，点「启用」随时切换。

> ⚠️ **本项目不含任何 API Key**，Key 由你自己填，存在你自己机器上的
> `data/config.json` 里。**不要把那个文件传到网上或提交进 git**（`.gitignore` 已排除）。

### 省钱 / 提速的开关

设置页里有两个：

- **改卷模式**：⚡快速（默认，约 15 秒）/ 🔍深度（更细，慢一些）
- **评分严格度**：🎯严格（默认，硬伤会压档）/ 🙂标准

## 常见问题

**口令忘了怎么办？**

再跑一次 `sh setup.sh` —— 会提示「直接回车保持不变」，这时输入新口令（输两遍）
就能重设。作文数据不会丢。

**网页打不开？**

看启动那个终端窗口的输出。最常见的是端口被占：

```bash
PORT=9000 sh setup.sh
```

**批改报「还没配置 AI 接口」？**

先去设置页填 API Key。填完刷新页面再批改。

**网页显示「请在终端运行 sh setup.sh 设置口令」？**

这是**故意的**：没设口令时网站整体锁定，不存在谁都能进的裸奔状态。
在终端进到本目录跑 `sh setup.sh`，按提示设个口令，刷新网页即可。
（设置页里改口令也不能留空 —— 留空等于把自己锁在门外。）

## 技术要点

- **纯 Flask，零构建**：前端就是原生 JS，没有 npm、没有打包器、没有 CDN
- **流式输出**：批改时逐字段推给前端（SSE），不用等整篇生成完
- **评分本地复算**：字数、扣分、定档由本地代码精确计算，不信 AI 报的数字
- **原子写盘**：作文 JSON 先写临时文件再 rename，写一半断电不会损坏
- **批注锚定**：AI 给的标红句必须**逐字**出现在原文里才标，找不到就宁可不标
- **口令不落明文**：PBKDF2-SHA256、39 万轮迭代、带盐
